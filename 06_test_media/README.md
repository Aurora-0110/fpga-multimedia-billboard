# TF卡素材由使用者自行准备

不公开原BMP、WAV、FLAC、歌词、转写、强制对齐时间轴和它们的派生历史位流/网表/截图。公开public_captions只含本项目新写的测试句，不是任何歌曲歌词。

可运行tools/generate_demo_media.py在新目录生成640×480无压缩24-bit BMP及48kHz/24-bit/双声道合成PCM WAV，不含原歌曲，也不会自动写TF。真实媒体命名为A.BMP至D.BMP、MUSIC.WAV、ADVOICE.WAV以及唯一额外WAV；扩展文件建议8.3短文件名。字幕由tools/generate_public_captions.py根据自编示例生成，替换音源时需自行准备有权使用的字幕与时间轴。
